# 반응형 디자인 시스템

uniconnect 화면 전체에 쓰는 크기·여백·누를 자리의 기준이다. 값은 `frontend/src/index.css`의 `:root` 토큰에 있고, 적용 규칙은 같은 파일 끝의 "반응형 디자인 시스템" 구역에 모여 있다. 지키는지는 `e2e/responsive.spec.ts`가 잰다(`docs/RESPONSIVE_QA_REPORT.md`).

새 화면이나 컴포넌트를 만들 때는 아래 토큰을 쓰고, 새 숫자를 만들지 않는다.

## 1. Breakpoints

콘텐츠가 깨지는 지점에 맞춘 다섯 단계다. 기기 이름이 아니라 레이아웃이 바뀌는 곳에 둔다.

| 너비 | 이름 | 바뀌는 것 |
|---|---|---|
| 1361px 이상 | Wide Desktop | 머리글에 다음 일정 알약과 역할 전환이 보인다 |
| 1101~1360px | Desktop | 카드 3~4열, 나란한 레이아웃 |
| 768~1100px | Tablet | 머리글의 페이지 링크가 Menu로 옮겨 가고, 나란한 레이아웃이 쌓인다. 좌우 여백 24px |
| 721~767px | Small Tablet | 태블릿 배치 그대로, 입력창은 16px(iOS 확대 방지) |
| 360~720px | Mobile | 1열, 카드는 한 줄에 하나, 팝업은 아래에서 올라온다. 좌우 여백 24px |
| 320~359px | Small Mobile | 좌우 여백 16px, 머리글 로고·알약을 줄여 메뉴가 밀려나지 않게 |

미디어 쿼리는 `max-width: 1360px`, `1100px`, `767px`, `720px`, `359px`만 쓴다.

## 2. Typography

글자 크기는 모두 `rem`(기본 16px = 1rem)이라, 브라우저의 글꼴 크기 설정을 따른다. 사용자 확대는 막지 않는다(`user-scalable`을 끄지 않음). iOS가 가로 화면에서 글자를 멋대로 키우지 않게 `text-size-adjust: 100%`를 둔다. PDF·카드 이미지로 내보내는 화면(`.pdf-export`, `.card-export`)만 인쇄 크기라 px를 쓴다.

| 토큰 | 크기 | 쓰는 곳 |
|---|---|---|
| `--text-2xs` | 11px | 일치율 링, 달력 칸, 그래프 눈금처럼 자리가 좁은 곳만 |
| `--text-xs` | 12px | 배지, 칩, 날짜, 상태 |
| (13px) | 0.8125rem | 안내 글(`field-hint`), 카드 보조 설명 |
| `--text-sm` | 14px | 보조 본문, 버튼 |
| `--text-base` | 16px | 본문, 휴대폰의 모든 입력창 |
| `--text-lg` | 18px | 카드 제목 |
| `--text-xl` | 22px | 섹션 소제목 |
| `--text-2xl` | 30px | 휴대폰 섹션 제목 |
| `--text-3xl` | 40px | 휴대폰 첫 화면 제목 |

- 줄 간격: 본문 `--leading-body` 1.6, 제목 `--leading-heading` 1.25(큰 제목은 1.1~1.2).
- 휴대폰 제목: 페이지 제목 32px, 섹션 제목 30px(줄을 고르게 나누는 `text-wrap: balance`), 첫 화면 40px, 고리 화면 42px.
- 넓은 화면 제목은 `clamp()`로 커지되 상한을 둔다(고리 화면 96px, ROAS 숫자 64px).
- 글자 크기를 `vw`만으로 정하지 않는다. `clamp(최소rem, vw, 최대rem)`처럼 쓴다.
- 한글: 20px 미만은 자간 0, 제목도 -0.03em보다 좁히지 않고, `word-break: keep-all`.

## 3. Spacing

`--space-1`~`--space-12`: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48px.

| 자리 | 값 |
|---|---|
| 좌우 여백(`--gutter`) | 데스크톱 32px, 태블릿·휴대폰 24px, 320~359px 16px |
| 카드 안쪽 | 16~24px, 위아래와 좌우를 같게 |
| 카드 사이 | 12~16px |
| 섹션 사이 | 48~96px(`clamp`) |

휴대폰에서는 상자 밖 글(섹션 제목, About 문장)도 상자와 같은 여백 선(24px)에서 시작한다.

## 4. Color Tokens

브랜드 색은 그대로다. 정의는 `index.css` `:root`.

| 토큰 | 뜻 |
|---|---|
| `--point` / `--on-point` | 진한 파랑 / 그 위의 글자 |
| `--point-strong` | 흰 바탕 위 파란 글자 |
| `--point-bright` / `--point-glow` | 흰 바탕 / 진한 파랑 위의 강조 파랑 |
| `--ink` / `--ink-soft` / `--muted` | 본문 / 보조 / 흐린 글 |
| `--fill` / `--fill-strong` / `--silver-gradient` | 은색 면 |
| `--line` / `--ring` | 헤어라인 |
| `--green` `--blue` `--violet` `--orange` `--red`(+`-soft`) | 상태 색. 흰 바탕의 작은 글씨에도 4.5:1 |

## 5. Border Radius

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--radius-sm` | 14px | 입력창, 작은 상자 |
| `--radius-md` | 20px | 일반 카드 |
| `--radius-lg` | 24px | 큰 패널, 팝업 |
| 999px | 알약 | 버튼, 칩, 탭 |

## 6. Grid & Width

- 콘텐츠 최대 너비 `--content-max`(1240px), 폼 `--form-max`(560px).
- 휴대폰은 1열. 태블릿은 콘텐츠에 따라 1~2열, 데스크톱은 2~4열(`auto-fit`, `minmax`).
- 고정 너비를 쓰지 않는다. 입력창·셀렉트·텍스트 영역은 `max-width: 100%`.
- 표와 차트는 휴대폰에서 막대·카드로 쌓거나, 그 상자 안에서만 가로로 스크롤한다(페이지는 가로로 스크롤되지 않는다).

## 7. Touch Targets

- `--touch-target` 44px: 휴대폰(767px 이하)에서 누르는 것은 높이 44px 이상(WCAG 2.5.5, Apple HIG).
- `--control-h` 44px, `--control-h-lg` 48px: 버튼·입력창 높이. 주요 CTA는 48px 이상.
- 아이콘 버튼(찜, 달력 이동, 비밀번호 보기)은 44×44px. 머리글 아이콘은 알약 안에서 40px(알약까지 44px).
- 글 크기의 버튼(카드 이름, 제안 취소)은 자리를 그대로 두고 `::after`로 누를 자리만 위아래로 넓힌다.
- 예외: 달력의 날짜 칸은 일곱 칸이 320px에 들어가야 해서 폭이 32~38px이다(높이는 40px 이상).

## 8. Component Rules

| 컴포넌트 | 규칙 |
|---|---|
| 버튼 | 알약(999px), 휴대폰 높이 44px, 글자 14~16px. 같은 줄의 버튼은 같은 높이 |
| 입력·셀렉트·텍스트 영역 | 휴대폰에서 16px(iOS 확대 방지, 이 한 곳만 `!important`), 높이 48px, `--radius-sm` |
| 카드 | `--radius-md`, 안쪽 16~24px로 위아래·좌우 같게. 휴대폰 카드의 버튼 넷은 한 줄 |
| 팝업(Modal) | 휴대폰에서 아래에서 올라오는 시트, 화면 밖으로 나가지 않음 |
| 머리글 | 고정 알약들. 휴대폰에서는 페이지와 함께 올라가 상태 표시줄 밑으로 흐려진다 |
| 탭·필터 | 은색 트랙의 알약, 휴대폰에서 탭 하나가 44×44px 이상. 좁으면 트랙 안에서 옆으로 스크롤 |
| 배지·칩 | 12px, 알약 |
| 푸터 | 링크 하나가 44px 높이(줄 간격 대신) |
| 빈 상태·오류 | `CatalogEmpty`, 토스트(`Toast`) 그대로 |
